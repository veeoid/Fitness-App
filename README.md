# 🏋️ Fitness App

A mobile fitness tracking application built with Java for Android, designed to help users stay on top of their health goals by tracking workouts, setting fitness milestones, and viewing progress metrics in real-time.

## 📱 Features

- **User Authentication**
  - Secure login and registration screens.
  - User session management for personalized data.

- **Workout Logging**
  - Add daily workouts with time, intensity, and category.
  - Support for cardio, strength, flexibility, and custom activities.

- **Progress Tracking**
  - Visual indicators of workout consistency and progress.
  - Weekly and monthly performance summary.

- **Clean UI**
  - Simple, intuitive interface for quick navigation.
  - Mobile-first layout optimized for Android devices.

## 🛠 Tech Stack

- **Language:** Java
- **Platform:** Android (Native)
- **Tools:** Android Studio, Gradle

## 🚀 Getting Started

### Prerequisites

- Android Studio (latest version)
- Android SDK 30+
- Java 8 or above

### Installation

1. Clone the repository:
```
   git clone https://github.com/veeoid/Fitness-App.git
```
Open the project in Android Studio.

Let Gradle sync and install dependencies.

Run the app on an emulator or physical device.
